# Swords & Souls Magic Auto

Автоматический помощник для магической тренировки в **Swords & Souls
Neverseen**.

## Что делает

- читает из памяти все активные типы целей: обычные, заполняемые облачные
  кольца, звёзды, гравитационные, преследующие и проходные кольца;
- удерживает настоящий курсор в безопасном центре игрового окна, как скрипт
  стрельбы из лука;
- для каждой появившейся цели выполняет штатную успешную цепочку игры
  `starHit → GetScored(true) → Sleep`;
- автоматически засчитывает заполнение облачного кольца и сбор звезды;
- корректно удаляет завершённые объекты из волны и возвращает их в пул;
- работает только пока окно игры находится на переднем плане.

## Установка и запуск

1. Установить 64-битный Python для Windows.
2. Один раз выполнить в этой папке:

   ```powershell
   pip install -r requirements.txt
   ```

3. Запустить игру и открыть магическую тренировку.
4. Дважды щёлкнуть `START.bat` и вернуться в игру.

В консоли должна появиться строка:

```text
Swords & Souls magic helper v1 is ready.
```

## Управление

- `F8` — пауза или продолжение;
- `F9` — завершение скрипта и закрытие его окна.

Скрипт не изменяет файлы игры. Он подключается к запущенному процессу и
работает только во время своего запуска. Полученные награды и прогресс могут
сохраняться самой игрой в обычном сохранении.
