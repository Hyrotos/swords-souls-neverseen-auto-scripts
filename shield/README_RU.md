# Swords & Souls Shield Auto

Автоматический помощник для тренировки щита в **Swords & Souls Neverseen**.

## Что делает

- читает активные снаряды непосредственно из памяти игры;
- определяет положение героя, щита и ближайшей опасности;
- автоматически направляет щит мышью для отражения опасных снарядов;
- за каждый успешно отбитый обычный снаряд начисляет одну звезду через
  штатную игровую систему подсчёта результата;
- не блокирует звёзды щитом: их коллайдер временно отключается, но обычное
  касание звездой тела героя продолжает работать;
- не двигает мышь, пока окно игры не находится на переднем плане.

## Запуск

### Windows

1. Установить 64-битный Python.
2. Один раз открыть командную строку в этой папке и выполнить:

   ```powershell
   pip install -r requirements.txt
   ```

3. Запустить игру и открыть тренировку щита.
4. Дважды щёлкнуть `START.bat` и вернуться в окно игры.

### Linux (Steam + Proton)

1. Из корня репозитория установить зависимости в виртуальное окружение
   проекта (Linux-зависимость `python-xlib` уже включена):

   ```sh
   .venv/bin/python -m pip install -r requirements.txt
   ```

2. Запустить игру через Proton и открыть тренировку щита.
3. Из корня репозитория выполнить `bash shield/START_LINUX.sh` и вернуться в
   окно игры. `F8` запускает или приостанавливает автоматизацию, `F9`
   завершает скрипт.

Linux-версия работает в сеансах X11 и Wayland (сама игра запущена под
XWayland): окно игры ищется через X11, мышь двигается через XTest. Захват
экрана не используется. Чтение памяти подключается к процессу Wine с помощью
Linux-сборки Frida; `wine_frida.py` предварительно исправляет вспомогательный
вектор процесса через `ptrace`, потому что иначе Frida аварийно завершается
внутри процесса Wine вместе с игрой. Если подключение запрещено, разрешите
его до перезагрузки: `sudo sysctl kernel.yama.ptrace_scope=0`.

В консоли должна появиться строка:

```text
Swords & Souls shield helper v3 is ready.
```

## Управление

- `F8` — пауза или продолжение автоматизации;
- `F9` — завершение скрипта и закрытие его окна.

## Файлы

- `autoshield.py` — управление положением щита;
- `shield_memory.py` — чтение снарядов и состояния тренировки из памяти;
- `linux_platform.py` — работа с окном, горячими клавишами и мышью в X11/XWayland;
- `wine_frida.py` — подготовка процесса игры под Wine/Proton для Frida;
- `START.bat` — файл запуска для Windows;
- `START_LINUX.sh` — файл запуска для Linux;
- `requirements.txt` — список зависимостей Python.

Скрипт не изменяет файлы игры. Он подключается к запущенному процессу и
работает только во время своего запуска. После обновления игры чтение памяти
может потребовать адаптации.
