# Swords & Souls Shield Auto

Автоматический помощник для тренировки щита в **Swords & Souls Neverseen**.

## Что делает

- читает активные снаряды непосредственно из памяти игры;
- определяет положение героя, щита и ближайшей опасности;
- автоматически направляет щит мышью для отражения опасных снарядов;
- за каждый успешно отбитый обычный снаряд начисляет одну звезду через
  штатную игровую систему подсчёта результата;
- не блокирует звёзды щитом: их коллайдер временно отключается, но обычное
  касание звездой тела героя продолжает работать;
- не двигает мышь, пока окно игры не находится на переднем плане.

## Запуск

1. Установить 64-битный Python для Windows.
2. Один раз открыть командную строку в этой папке и выполнить:

   ```powershell
   pip install -r requirements.txt
   ```

3. Запустить игру и открыть тренировку щита.
4. Дважды щёлкнуть `START.bat` и вернуться в окно игры.

В консоли должна появиться строка:

```text
Swords & Souls shield helper v3 is ready.
```

## Управление

- `F8` — пауза или продолжение автоматизации;
- `F9` — завершение скрипта и закрытие его окна.

## Файлы

- `autoshield.py` — управление положением щита;
- `shield_memory.py` — чтение снарядов и состояния тренировки из памяти;
- `START.bat` — файл запуска;
- `requirements.txt` — список зависимостей Python.

Скрипт не изменяет файлы игры. Он подключается к запущенному процессу и
работает только во время своего запуска. После обновления игры чтение памяти
может потребовать адаптации.
