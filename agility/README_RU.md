# Swords & Souls Agility Auto

Автоматическое уклонение и контратака в тренировке ловкости Swords & Souls Neverseen.

Скрипт читает направление и скорость атаки непосредственно из памяти игры. Он прогнозирует момент проверки удара и нажимает нужную клавишу в последний безопасный момент. Когда появляется окно атаки манекена, скрипт отдельно читает ожидаемую сторону и нажимает `A` или `D`. Ускорение тренировки учитывается автоматически.

## Запуск

1. Запустите игру и откройте тренировку ловкости.
2. Дважды нажмите `START.bat`.
3. Вернитесь в окно игры.

Управление:

- `F8` — пауза или продолжение.
- `F9` — завершение скрипта и закрытие его окна.

Если зависимости ещё не установлены:

```bat
pip install -r requirements.txt
```

Дополнительная настройка прогноза:

```bat
python autododge.py --lead-ms 32
```

Чем больше `lead-ms`, тем раньше выполняется уклонение. Значение по умолчанию подобрано по фактическому моменту удара игры.

## Linux (Steam + Proton)

1. Из корня репозитория установить зависимости в виртуальное окружение
   проекта (Linux-зависимость `python-xlib` уже включена):

   ```sh
   .venv/bin/python -m pip install -r requirements.txt
   ```

2. Запустить игру через Proton и открыть тренировку ловкости.
3. Из корня репозитория выполнить `bash agility/START_LINUX.sh`, вернуться в
   окно игры и держать указатель мыши внутри него. `F8` запускает или
   приостанавливает автоматизацию, `F9` завершает скрипт.

Linux-версия работает в сеансах X11 и Wayland (сама игра запущена под
XWayland). Нажатия W/A/S/D и клавиши F8/F9 обрабатываются через X11/XTest. Захват экрана не
используется. `linux_platform.py` — этот X11-модуль; `wine_frida.py`
подготавливает процесс Wine, чтобы Linux-сборка Frida могла подключиться, не
завершая игру. Если подключение запрещено, разрешите его до перезагрузки:
`sudo sysctl kernel.yama.ptrace_scope=0`.
