# Swords & Souls Sword Auto

Автоматический помощник для тренировки меча в **Swords & Souls Neverseen**.

## Что делает

- автоматически нажимает `W`, `A` и `D` для соответствующих направлений;
- читает из памяти игры обычные летящие предметы и атаки манекенов;
- использует отдельную защиту от повторных нажатий;
- при недоступности чтения памяти может перейти на визуальное распознавание;
- не отправляет клавиши, пока окно игры не находится на переднем плане.

## Запуск

### Windows

1. Установить 64-битный Python.
2. Открыть командную строку в этой папке и установить зависимости:

   ```powershell
   pip install -r requirements.txt
   ```

3. Запустить игру и открыть тренировку меча.
4. Дважды щёлкнуть `START_FIXED.bat` и вернуться в окно игры.

### Linux (Steam + Proton)

1. Из корня репозитория установить зависимости в виртуальное окружение
   проекта (Linux-зависимости включены):

   ```sh
   .venv/bin/python -m pip install -r requirements.txt
   ```

2. Запустить игру через Proton и открыть тренировку меча.
3. Из корня репозитория выполнить `bash sword/START_LINUX.sh` и вернуться в
   окно игры. `F8` включает/приостанавливает автоматизацию, `F9` завершает
   помощник.

Linux-версия работает в сеансах X11 и Wayland (сама игра запущена под
XWayland) и отправляет клавиши через XTest. Как и в Windows, атаки манекенов
и летящие предметы читаются из памяти игры: `wine_frida.py` подготавливает
процесс Wine, чтобы Linux-сборка Frida могла подключиться, не завершая игру.
Если подключение запрещено, разрешите его до перезагрузки:
`sudo sysctl kernel.yama.ptrace_scope=0`.

Захват экрана остаётся только запасным вариантом на случай, если чтение
памяти недоступно. В X11 используется MSS; в Wayland — портал ScreenCast и
PipeWire, для чего нужен GStreamer с плагином PipeWire (`gst-launch-1.0` и
`pipewiresrc`) и разрешение на захват окна **Swords & Souls Neverseen**.

В консоли должна появиться строка:

```text
Swords & Souls helper v27 (exact memory timing) is ready.
```

## Управление

- `F8` — пауза или продолжение автоматизации;
- `F9` — завершение скрипта и закрытие его окна.

## Файлы

- `autoplayer.py` — основная логика;
- `autoplayer_fixed.py` — правильная настройка ввода для 64-битной Windows;
- `mannequin_memory.py` — чтение состояния тренировки из памяти Unity/Mono;
- `START_FIXED.bat` — рекомендуемый файл запуска;
- `requirements.txt` — список зависимостей Python.

Скрипт не изменяет файлы игры. Он подключается к запущенному процессу и
работает только во время своего запуска. После обновления игры чтение памяти
может потребовать адаптации.
